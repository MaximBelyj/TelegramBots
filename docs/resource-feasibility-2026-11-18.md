# Аудит способов получения данных: все 36 ресурсов

**Дата: 18 ноября 2026 года. Версия отчёта: audit-v1.0. Код и настройки бота в этом этапе не переписаны.**

## Главное

- Исследованы все 36 записей: главные страницы, robots.txt, где доступны — формы поиска, публичные JavaScript-маршруты, sitemap, документация API, прайсы и контрольные ответы. HTTP 200 главной не считается доказательством товарного поиска.
- В прежней классификации были ошибки. GetChip сейчас показывает панель температуры, а не магазин. Прежняя оценка некоторых правил robots.txt не учитывала маски `*`; для этого аудита проверка выполнена Protego 0.7.0. Старые отметки «поиск разрешён» для Симметрона, Чипстера, Радиоэксперта и Радиотеха следует считать исправленными.
- У Платана найден и проверен официальный API без логина/ключа: `https://shop.platan.ru/export/price.json?search=LM358` вернул JSON с 89 позициями. Документация: [API](https://www.platan.ru/company/api.html), [PDF](https://www.platan.ru/api.pdf), [лимиты и рекомендации](https://www.platan.ru/api_load.pdf). Поиск каталога отличается от заказа/индивидуальной цены, которым нужен доступ. Лимиты опубликованы поставщиком, они могут меняться.
- У DESSY опубликован [XLS-прайс](https://www.dessy.ru/include/zips/price_konstruktory.xls): файл прочитан xlrd 2.0.2, 29 строк на листе СМАЙЛ, включая заголовки. Это часть конструкторов, не весь магазин; оперативный остаток нужно уточнять у поставщика.
- У ЭФО найден рабочий HTTPS-адрес без `/ru/`; контроль `OKW` дал 235 позиций, `LM358` — явный ноль. Сайт сообщает обновление количества раз в сутки.
- Доступ через официальный поисковый индекс остаётся неполным резервом: он не подтверждает весь ассортимент, наличие или цену. Нельзя считать внутренний `/api` сайта официальным внешним API без документации.

## Как интерпретировать выводы

- Проверен конкретный способ: **9** ресурсов. Это не число уже внедрённых адаптеров и не гарантия полного каталога.
- Частично подтверждён маршрут: **10**. Нужны перечисление карточек, проверка полноты/пагинации или согласование выгрузки.
- Нужен доступ/согласование: **9**.
- Сетевой/серверный блок исследования: **7**.
- Неподходящий текущий ресурс: **1**.

503 нельзя автоматически называть антиботом: у ряда сайтов получен текст `upstream connect error` от промежуточной сети, а у eFind — браузерная проверка; у Сириуса — страница проверки безопасности. Элитан явно сообщает региональное ограничение РФ. Ни один из этих случаев не доказывает, что магазин не работает у обычных посетителей.

Sitemap содержит адреса, а не обязательно цены/остатки. Найденная ссылка на прайс не равна проверенной машинной загрузке: у Радиоэксперта страница прайса доступна, но путь файла закрыт правилами, поэтому файл не скачивался. Разрешение robots.txt не заменяет условия использования; отсутствие robots.txt само по себе не даёт специальных прав доступа.

Для сайтов, закрывших поиск, допустимый обход каталога/карточек — отдельный способ, а не попытка изменить параметры того же закрытого поиска или подменить User-Agent Googlebot. CAPTCHA, чужие cookies, скрытые API, ротация адресов для обхода блокировки, отправка заказов и автоматические обращения к сотрудникам не использовались.

1. Официальный API Платана; DESSY XLS+HTML; правильный складской поиск ЭФО; HTML Сети электронных компонентов, Radio Shop, ChipFind и Радиосилы.

Текущие адаптеры бота и его процессы этим аудитом не менялись. Результаты не встраивались в пользовательский архив. В репозиторий сохраняются только выводы и технические метаданные проверок; полные HTML, PDF, XLS, карточки, личные IP-адреса, значения cookies/полей и секреты не публикуются.
