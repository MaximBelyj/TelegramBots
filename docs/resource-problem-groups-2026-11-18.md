## Что оставляем без поиска новых способов доступа

Нельзя смешивать работающий адаптер в боте и найденный рабочий способ доступа. Для двух ресурсов подтверждён поиск существующим адаптером; для шести способ проверен отдельным запросом, но его подключение/доработка ещё требуется. Их повторно не исследовал. Амперка перенесена из прежней широкой категории «проверенный способ» в доработку: доступны sitemap и карточка, но полного поискового сценария ещё нет.

## Проблемные ресурсы: решать группами

**VPN:** нет оснований объявлять все отказы его следствием. Только Элитан явно ограничивает страну IP. Важна обслуживаемая сеть, а не наличие приложения VPN. Для 503 сравнивались тексты ошибок; upstream-сбой отделён от браузерной проверки.

Это подтверждённая география, а не доказательство запрета любого VPN. | Использовать обслуживаемую сайтом разрешённую сеть РФ или согласовать внешний доступ/выгрузку с поставщиком. Для VPN важна страна выходного IP; российский адрес сам по себе не гарантирует доступ. | Причина ограничения подтверждена текстом сайта. Российская рабочая среда/согласованный фид здесь не проверены. ## Что дополнительно сделано

- Не повторялись проверки восьми отложенных в рабочую группу ресурсов.
- Для сетевой группы проверен локальный DNS без публикации IP. У пяти upstream-503 домены разрешаются; это не доказывает исправность DNS/соединения внутри внешнего прокси.
- У tangenta.ru и www.tangenta.ru результаты DNS различаются: основной не найден локальным резолвером, www даёт IPv4. При этом предыдущий HTTP через прокси на www всё равно был 503. Один выбор www не объявляется исправлением.
- Для группы закрытого поиска дополнительно проверены товарная карта Промэлектроники, карта Elecomp и разрешение контрольных путей карточек. Для части группы общий подход подтверждён, но это не доказательство полного охвата всех девяти сайтов.
- Для Elecomp первые URL первой карты оказались категориями; во второй карте получены товарные URL, и их пути разрешены robots. Сами карточки этой новой выборки и полный каталог не загружались.
- Результаты каждой новой проверки сохранены как технические метаданные в JSON ниже. Нет личных IP, cookies, заголовков с ключами и пользовательских запросов.

## Порядок дальнейшей реализации

1. Оставить QRZ.ru и DESSY; интегрировать шесть уже найденных рабочих маршрутов, не искать им новых обходов.
2. Одним общим механизмом решать группу sitemap/карточек: девять ресурсов с закрытым поиском плюс РУСЭЛТ. Сначала ресурсы с проверенными картами/карточками, затем ZIP/RoboShop.
3. Отдельно решать сетевой доступ, региональное ограничение и квоты. Пока внешний доступ не восстановлен, считать эти подключения неготовыми.
4. Для защитных проверок применять только поддерживаемые способы получения данных. Индексный API даёт ограниченные ссылки, а не весь каталог или наличие. Смена IP/маскировка клиента не объявляется готовым устойчивым решением.
