# Индексный поиск Ozon и Wildberries — v0.1.6

## Что решает подключение

Прямые поисковые страницы Ozon и Wildberries в локальной проверке видимого Chromium вернули 403 и 498. Причина, связанная с конкретным признаком клиента, не доказана. Ротация адресов, маскировка автоматизации и решение CAPTCHA не реализуются.

Вместо запросов к этим страницам добавлен официальный Brave Web Search API. После подключения ключа бот ищет `site:ozon.ru <запрос>` и `site:wildberries.ru <запрос>`, оставляет только товарные ссылки и ранжирует их по исходному названию изделия. Все запросы идут на фиксированный `https://api.search.brave.com/res/v1/web/search`, заголовок `X-Subscription-Token`. Переадресации API не выполняются, чтобы ключ не попал на другой адрес.

Документация, прочитанная при реализации: https://api-dashboard.search.brave.com/app/documentation/web-search/get-started — подтверждены endpoint, заголовок, оператор `site:`, параметр `count` до 20 и ответ `web.results`. Это официальный поисковый интерфейс, а не внутренний endpoint маркетплейсов. Seller API Ozon/Wildberries для этой задачи не подключён: подходящий доступ к общему каталогу разных продавцов не подтверждён. Документация WB в текущей сети возвращала 498, страница Ozon — оболочку; доступность их возможностей не заявляется по этим ответам.

**Это поиск по индексу, а не полноценная выдача маркетплейса.** Новые, неиндексируемые и удалённые страницы могут отсутствовать или быть устаревшими. Цена, продавец, наличие и дата публикации не придумываются и не выводятся из поисковых сниппетов. Бот помечает источник результатов и ограниченный охват. Автоматическое чтение закрытых карточек не выполняется. Названия запросов передаются провайдеру поиска; товарные результаты в локальной базе не сохраняются.

## Подключение

1. В кабинете https://api-dashboard.search.brave.com/ получить API-ключ с доступом к Web Search, проверить тариф, квоту и допустимые способы использования. Подписка на браузер или другой продукт не заменяет API-доступ. Доступ может быть платным; покупка/подписка автоматически не оформляется.
2. В защищённых настройках среды добавить `BRAVE_SEARCH_API_KEY`. Не отправлять значение в чат и не добавлять в Git. Для прокси-секрета разрешённое назначение — `api.search.brave.com`.
3. Необязательный `BRAVE_SEARCH_DAILY_LIMIT`: положительное число запросов в сутки, по умолчанию 100 на один экземпляр бота, общих для всех пользователей и обеих площадок. Сутки отсчитываются по Москве. Это лимит количества запросов, не денежного счёта провайдера.
4. После применения переменных перезапустить один процесс бота и проверить доступность Ozon/Wildberries в разделе «Площадки». Эта проверка тоже расходует квоту. Затем выполнить поиск гражданского изделия.

До появления ключа поведение прежних источников не меняется. Наличие ключа само по себе не означает успешное подключение. При подключённом ключе Ozon/Wildberries используют только индексный маршрут; возврата к заблокированным страницам при сбое API нет. Прежние статусы прямого доступа сохраняются отдельно от `ozon:brave` и `wb:brave`, чтобы их паузы не сбрасывались при переключении.

`data/brave_usage.json` рядом с файлом статусов содержит только дату и число исходящих API-запросов, включая неудачные попытки. Квота не сбрасывается перезапуском. Этот локальный лимит не синхронизируется между разными машинами с одним ключом. Интервал между API-запросами не менее двух секунд; дополнительно сохраняются очереди сайтов. Отказы авторизации и API 429 блокируют оба индексных источника, в том числе после перезапуска. Соблюдается Retry-After. Файлы пауз и счётчик удалять для снятия ограничений нельзя.

## Степень проверки

67 тестов включают разбор JSON, фильтрацию доменов/товарных URL, взвешенное ранжирование, пометку индекса, запрет перенаправления ключа, общий лимит и паузы. Ответы поискового API в тестах искусственные. Настоящий ключ отсутствовал: реальный успешный запрос и полнота результатов не подтверждены. Подключение не следует считать работающим до этой проверки. Покупка API-доступа пользователем не гарантирует наличие нужных товаров в индексе.
