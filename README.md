# Личный бот поиска товаров

## Меню

Отправьте `/start` или `/menu`, чтобы открыть кнопки:

- **Найти сейчас**: выбрать изделие из списка или искать все изделия.
- **Изделия**: список с перелистыванием, поиском и удалением отдельной позиции.
- **Добавить**: введите название или несколько названий, каждое с новой строки. Повторы без учёта регистра не добавляются. Название — от 2 до 200 символов. `/menu` отменяет ввод.
- **Удалить**: выбрать позицию и подтвердить удаление. Текущий ручной поиск останавливается; автопоиск перезапускается с обновлённым списком.
- **Площадки**: Ozon, Яндекс Маркет, Avito, Wildberries, Чип и Дип, Платан, Промэлектроника, QRZ.ru, RadioKot или все сразу. Выбор применяется к следующим запросам ручного и автоматического поиска.
- **Автопоиск**: включение и выключение. При включении первый цикл начинается сразу; после завершения полного цикла пауза 30 минут. Между изделиями пауза 3 секунды. Выключение отменяет текущий автоматический поиск. Состояние сохраняется при перезапуске.
- **Остановить поиск**: отменяет ручной и автоматический поиски, выключает автопоиск.

Также доступен `/find текст` (или `/search текст`) для разового запроса без добавления в список. Доступ только владельцу в личном чате.

## Данные

**Хранение результатов отключено.** Поиск передаёт найденные результаты в Telegram, без записи в SQLite, скачивания карточек и отслеживания объявлений. Повторные результаты могут приходить снова. Сообщения остаются в самом Telegram, пока пользователь их не удалит.

В `data/preferences.sqlite3` хранятся только названия изделий, выбранная площадка и переключатель автопоиска. На первом запуске добавляется DMR, все площадки, автопоиск выключен. `DMR_SETTINGS_PATH` переопределяет путь настроек. Старый `data/archive.sqlite3` не используется и не удаляется. Прежние команды сохранения/истории отключены. Модули старого архива сохранены в репозитории, но не вызываются работающим ботом.

Из нового RTF выбраны 8 общепромышленных позиций: `catalog/civilian_products.txt`. Весь файл не импортируется: он также содержит вооружение и специализированные компоненты. В момент обновления все 86 строк уже были в пользовательском списке: 78 неотобранных строк исключены из активного списка с сохранением полной копии настроек в `data/preferences.before-weighted-search.sqlite3`; 5 других существовавших позиций сохранены. Не восстанавливайте полную копию автоматически в активный поиск. Исходный RTF не включён в код. Повторный импорт при запуске не выполняется, поэтому удалённые пользователем позиции не возвращаются.

## Специализированные сайты

Новые сайты включены в тот же раздел «Площадки»; отдельной кнопки нет. Выбранный источник применяется ко всем текущим и будущим изделиям в ручном и автоматическом поиске. «Все сразу» автоматически включает весь реестр источников (`SOURCES`), без привязок к отдельным изделиям.

| Сайт | Проверка подключения |
| --- | --- |
| Платан | Получены реальные карточки LM358; поддержана кодировка Windows-1251 |
| Промэлектроника | Получены реальные карточки LM358; при повторных запросах встречается HTTP 403 |
| QRZ.ru | Прочитана выдача гражданских трансиверов; проверен ответ без совпадений. Реклама/VIP вне основной выдачи исключена |
| Чип и Дип | Адаптер добавлен, автоматический доступ сейчас ограничен HTTP 403/DDoS-Guard; реальная выдача не проверена |
| RadioKot | Адаптер форумных тем добавлен, автоматический доступ ограничен HTTP 403; разбор реальной выдачи не проверен |

При блокировке или неподдерживаемой разметке бот сообщает об этом и даёт ссылку на ручной поиск. Подключённый сайт не означает гарантированную доступность. Результаты каталога или форума не гарантируют наличие товара, возможность покупки или актуальность объявления. Для RadioKot идентификаторы тем сохраняются в ссылке, сессионные параметры удаляются. Приватные разделы и авторизация не используются.

## Ограничения поиска

Алгоритм взвешенного поиска пока экспериментальный (`dmr_bot/matching.py`):

- Артикул/модель: 8 баллов; характерное слово: 2; общее слово типа «устройство» или «блок»: 0,5; предлоги: 0. Повтор слова не увеличивает вес.
- Регистр, ё/е, варианты тире нормализуются. У артикулов разрешены различия пробелов и разделителей; цифры не исправляются и не сравниваются приблизительно. Для слов применена ограниченная эвристика окончаний, без полноценного морфологического словаря.
- Полная модель может пройти самостоятельно. Без модели нужны минимум два существенных слова; для однословного запроса без модели достаточно самого слова. Одного общего слова недостаточно. Другая явно указанная модель при несовпадении запрошенной отклоняется; параметры вроде «24В» сами по себе другой моделью не считаются. Это эвристика, сложные обозначения могут требовать настройки.
- До трёх запросов на площадку: исходное название, модель отдельно, сокращённое описание. Кандидаты оцениваются по исходному названию; ссылки объединяются, точная модель ранжируется первой, затем сумма весов. Между вариантами пауза 1 секунда. Заблокированный источник не повторяется вариантами.
- Результат показывает совпавшие признаки, баллы и покрытие весов исходного названия. Покрытие — не вероятность и не гарантия идентичности товара. Несколько подходящих объявлений показываются вместе, а не только один победитель.

Используются публичные HTML/JSON-LD страницы. Читается первая доступная страница каждого варианта, до 20 кандидатов с неё, затем выводится до 20 объединённых подходящих результатов площадки. Ошибки отдельных вариантов отражаются предупреждением, доступные результаты сохраняются только в памяти на время поиска и отправляются в Telegram. Цены и продавцы могут отсутствовать. Полный охват не гарантируется.

Ранее реальная выдача проверена на Ozon и Яндекс Маркете. Avito блокировался прокси, Wildberries возвращал HTTP 498. Доступ может меняться. Ошибки, CAPTCHA и неизвестная разметка показываются как недоступность, а не отсутствие товаров. Обход защиты не выполняется. При недоступности есть ссылка на ручной поиск.

## Установка и запуск

```bash
cd /workspace/TelegramBots
python -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m dmr_bot.bot
```

В защищённых настройках среды должны быть `TELEGRAM_BOT_TOKEN` и числовой `TELEGRAM_OWNER_ID`. Не публикуйте токен. Клиент Telegram использует системный прокси и проверку TLS.

Проверка: владелец отправляет `/start`, добавляет гражданский товар через кнопку, выбирает площадку, запускает поиск и проверяет отключение автопоиска. Список и настройки должны сохраняться после перезапуска; новые снимки в старом архиве появляться не должны. Тесты меню используют искусственные Telegram-обновления, без отправки сообщений реальным пользователям.

Держите только один процесс бота. Публикация среды разработки не обеспечивает круглосуточный хостинг. При восстановлении среды запустите процесс заново.
