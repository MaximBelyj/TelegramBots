# Личный бот поиска товаров — v0.1.6

## Меню

Отправьте `/start` или `/menu`, чтобы открыть кнопки:

- **Найти сейчас**: выбрать изделие из списка или искать все изделия.
- **Изделия**: список с перелистыванием, поиском и удалением отдельной позиции.
- **Добавить**: введите название или несколько названий, каждое с новой строки. Повторы без учёта регистра не добавляются. Название — от 2 до 200 символов. `/menu` отменяет ввод.
- **Удалить**: выбрать позицию и подтвердить удаление. Текущий ручной поиск останавливается; автопоиск перезапускается с обновлённым списком.
- **Площадки**: Ozon, Яндекс Маркет, Avito, Wildberries, Чип и Дип, Платан, Промэлектроника, QRZ.ru, RadioKot или все сразу. Выбор применяется к следующим запросам ручного и автоматического поиска.
- **Автопоиск**: включение и выключение. При включении первый цикл начинается сразу; после завершения полного цикла пауза 30 минут. Между изделиями пауза 3 секунды. Выключение отменяет текущий автоматический поиск. Состояние сохраняется при перезапуске.
- **Остановить поиск**: отменяет ручной и автоматический поиски, выключает автопоиск.

Также доступен `/find текст` (или `/search текст`) для разового запроса без добавления в список. Доступ в личном чате владельцу и явно разрешённым аккаунтам; у каждого отдельные список изделий, настройки и задачи.

## Данные

**Хранение результатов отключено.** Поиск передаёт найденные результаты в Telegram, без записи в SQLite, скачивания карточек и отслеживания объявлений. Повторные результаты могут приходить снова. Сообщения остаются в самом Telegram, пока пользователь их не удалит.

В `data/preferences.sqlite3` хранятся только названия изделий, выбранная площадка и переключатель автопоиска. В `data/source_health.json` дополнительно сохраняются статусы доступа и сроки пауз без результатов, параметров URL и cookies. На первом запуске добавляется DMR, все площадки, автопоиск выключен. `DMR_SETTINGS_PATH` переопределяет путь настроек. Старый `data/archive.sqlite3` не используется и не удаляется. Прежние команды сохранения/истории отключены. Модули старого архива сохранены в репозитории, но не вызываются работающим ботом.

Из нового RTF выбраны 8 общепромышленных позиций: `catalog/civilian_products.txt`. Весь файл не импортируется: он также содержит вооружение и специализированные компоненты. В момент обновления все 86 строк уже были в пользовательском списке: 78 неотобранных строк исключены из активного списка с сохранением полной копии настроек в `data/preferences.before-weighted-search.sqlite3`; 5 других существовавших позиций сохранены. Не восстанавливайте полную копию автоматически в активный поиск. Исходный RTF не включён в код. Повторный импорт при запуске не выполняется, поэтому удалённые пользователем позиции не возвращаются.

## Специализированные сайты

Новые сайты включены в тот же раздел «Площадки»; отдельной кнопки нет. Выбранный источник применяется ко всем текущим и будущим изделиям в ручном и автоматическом поиске. «Все сразу» охватывает весь реестр источников (`SOURCES`), без привязок к отдельным изделиям. Автоматически запрашиваются только прошедшие проверку сайты; остальные дают ручную ссылку. В том же разделе есть статусы и кнопка «Проверить доступность».

| Сайт | Проверка подключения |
| --- | --- |
| Платан | Получены реальные карточки LM358; поддержана кодировка Windows-1251 |
| Промэлектроника | Получены реальные карточки LM358; при повторных запросах встречается HTTP 403 |
| QRZ.ru | Прочитана выдача гражданских трансиверов; проверен ответ без совпадений. Реклама/VIP вне основной выдачи исключена |
| Чип и Дип | Адаптер добавлен, автоматический доступ сейчас ограничен HTTP 403/DDoS-Guard; реальная выдача не проверена |
| RadioKot | Адаптер форумных тем добавлен, автоматический доступ ограничен HTTP 403; разбор реальной выдачи не проверен |

При блокировке или неподдерживаемой разметке бот сообщает об этом и даёт ссылку на ручной поиск. Подключённый сайт не означает гарантированную доступность. Результаты каталога или форума не гарантируют наличие товара, возможность покупки или актуальность объявления. Для RadioKot идентификаторы тем сохраняются в ссылке, сессионные параметры удаляются. Приватные разделы и авторизация не используются.

## Ограничения поиска

Алгоритм взвешенного поиска пока экспериментальный (`dmr_bot/matching.py`):

- Артикул/модель: 8 баллов; характерное слово: 2; общее слово типа «устройство» или «блок»: 0,5; предлоги: 0. Повтор слова не увеличивает вес.
- Регистр, ё/е, варианты тире нормализуются. У артикулов разрешены различия пробелов и разделителей; цифры не исправляются и не сравниваются приблизительно. Для слов применена ограниченная эвристика окончаний, без полноценного морфологического словаря.
- Полная модель может пройти самостоятельно. Без модели нужны минимум два существенных слова; для однословного запроса без модели достаточно самого слова. Одного общего слова недостаточно. Другая явно указанная модель при несовпадении запрошенной отклоняется; параметры вроде «24В» сами по себе другой моделью не считаются. Это эвристика, сложные обозначения могут требовать настройки.
- До трёх запросов на площадку: исходное название, модель отдельно, сокращённое описание. Кандидаты оцениваются по исходному названию; ссылки объединяются, точная модель ранжируется первой, затем сумма весов. Запросы проходят отдельную очередь каждого сайта: 10–15 секунд после предыдущего запроса. После первого отказа остальные варианты не запрашиваются, даже если предыдущий вариант был успешен.
- Результат показывает совпавшие признаки, баллы и покрытие весов исходного названия. Покрытие — не вероятность и не гарантия идентичности товара. Несколько подходящих объявлений показываются вместе, а не только один победитель.

Используются публичные HTML/JSON-LD страницы. Читается первая доступная страница каждого варианта, до 20 кандидатов с неё, затем выводится до 20 объединённых подходящих результатов площадки. Ошибки отдельных вариантов отражаются предупреждением, доступные результаты сохраняются только в памяти на время поиска и отправляются в Telegram. Цены и продавцы могут отсутствовать. Полный охват не гарантируется.

Ранее реальная выдача проверена на Ozon и Яндекс Маркете. Avito блокировался прокси, Wildberries возвращал HTTP 498. Доступ может меняться. Ошибки, CAPTCHA и неизвестная разметка показываются как недоступность, а не отсутствие товаров. Обход защиты не выполняется. При недоступности есть ссылка на ручной поиск.

## Установка и запуск

```bash
cd /workspace/TelegramBots
python -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m dmr_bot.bot
```

В защищённых настройках среды должны быть `TELEGRAM_BOT_TOKEN` и числовой `TELEGRAM_OWNER_ID`. Не публикуйте токен. Клиент Telegram использует системный прокси и проверку TLS.

Проверка: владелец отправляет `/start`, добавляет гражданский товар через кнопку, выбирает площадку, запускает поиск и проверяет отключение автопоиска. Список и настройки должны сохраняться после перезапуска; новые снимки в старом архиве появляться не должны. Тесты меню используют искусственные Telegram-обновления, без отправки сообщений реальным пользователям.

На новой среде без сохранённого файла доступности сначала выполните `.venv/bin/python -m dmr_bot.search_engine` или нажмите «Проверить доступность» в разделе «Площадки». Подробные наблюдения, паузы и ограничения: [диагностика доступа](docs/access-diagnostics.md). Сохранение настроек среды и публикация кода не выполняют диагностику и не запускают процесс автоматически.

Каждое обновление кода публикуется отдельным коммитом с уникальным Git-тегом версии; текущая версия `v0.1.6`. Для восстановления старого кода используйте отдельный checkout нужного тега, не сбрасывая пользовательские данные и секреты.

Держите только один процесс бота. Публикация среды разработки не обеспечивает круглосуточный хостинг. При восстановлении среды запустите процесс заново.

## Диагностика на macOS

Для сравнения домашней сети с облаком выполните `bash scripts/macos-check.sh` в локальной копии репозитория. Помощник подготовит зависимости и создаст отчёт без токена Telegram и без запуска второго бота. Пошагово: [инструкция для macOS](docs/macos.md). Локальные файлы отчёта и пауз остаются в игнорируемой папке `data/`.

## Дополнительные пользователи

Владелец определяется через `TELEGRAM_OWNER_ID` и всегда имеет доступ. Дополнительные аккаунты указываются в локальном `data/access.json` (переопределение `DMR_ACCESS_PATH`):

```json
{"allowed_user_ids": [123456789]}
```

Число в примере нужно заменить реальным Telegram ID. Файл не публикуется в Git. Изменение доступа применяется после перезапуска одного процесса бота. Отсутствующий файл оставляет доступ только владельцу; некорректный файл останавливает запуск, не открывая общий доступ.

Для владельца сохраняется прежний `DMR_SETTINGS_PATH` (по умолчанию `data/preferences.sqlite3`). Остальные аккаунты получают собственную базу в `users/<Telegram ID>/preferences.sqlite3` рядом с базой владельца. В новой базе только стартовый запрос DMR, все площадки и выключенный автопоиск. Пользователь добавляет свои изделия самостоятельно. Списки, ввод, удаление, выбранная площадка, автопоиск, остановка и ответы разделены по пользователям. Существующий список владельца не копируется и не удаляется.

Очереди сайтов и защитные паузы остаются общими для всех аккаунтов, поскольку используется один сервер. Бот не открыт всем: неразрешённые аккаунты и групповые чаты игнорируются. После добавления пользователь должен сам отправить `/start`; приглашения и сообщения от имени владельца автоматически не отправляются. При переносе сохранить нужно и `data/access.json`, и базы `data/users/`, и прежние настройки/статусы источников. Конкретные ID пользователей в исходном коде не зашиты.

Для следующего этапа локальной диагностики RadioKot/Ozon/Wildberries используйте `bash scripts/macos-check.sh browser`: отдельный видимый Chromium, без токена Telegram. Отчёт `data/macos-browser-report.json` содержит только структурные признаки. Подробности и ограничения — в [инструкции macOS](docs/macos.md). Браузерный сбор в рабочий бот не подключён; доступность и допустимость такого подключения пока не подтверждены.

В v0.1.5 уточнён обработчик phpBB-поиска RadioKot: форма поиска может присутствовать вместе с результатами. После обновления локальной копии повторите только RadioKot через `bash scripts/macos-check.sh browser-radiokot`; отчёт `data/macos-radiokot-report.json`. На реальной странице Mac исправление пока не подтверждено. Ozon/Wildberries в предыдущей видимой проверке вернули 403/498; браузерный режим автоматически к боту не подключается.

## Поиск Ozon/Wildberries через официальный поисковый API

В v0.1.6 подготовлен альтернативный маршрут через Brave Search API. Требуется секрет `BRAVE_SEARCH_API_KEY`; без него подключение не активировано. Результаты отражают индекс, не весь каталог и не текущее наличие товара. После подключения ключа эти два источника не запрашивают заблокированные страницы; остальные работают как прежде. Лимит по умолчанию — 100 API-запросов в сутки по Москве на экземпляр бота, изменяется через `BRAVE_SEARCH_DAILY_LIMIT`. Ключ/тариф и живой запрос пока не проверены. Подробности, ограничения и подключение: [поиск по индексу](docs/search-index.md).
